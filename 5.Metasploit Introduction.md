# 🛠️ Metasploit Framework (MSF) Ders Notları & Rehber 🚀

## 📋 Metasploit Temel Terimleri (Core Concepts)
Metasploit kullanırken sıkça karşılaşacağınız temel siber güvenlik kavramları:

* **Zafiyet (Vulnerability)**: Hedef sistemdeki tasarım, kodlama veya mantık hatasıdır. Saldırganın yetkisiz işlem yapmasına olanak tanır.
* **Exploit (İstismar Betiği)**: Hedefteki bir zafiyeti sömürmek ve sistemi ele geçirmek için yazılmış kod parçasıdır.
* **Payload (Zararlı Yük)**: Exploit başarıyla çalıştıktan sonra hedef sistemde çalıştırılan kod veya komuttur (örn. ters bağlantı açma, komut çalıştırma vb.).

---

## 📦 Metasploit Modülleri ve Kategorileri
Metasploit Framework içerisinde belirli görevleri yerine getiren 7 temel modül kategorisi bulunur:

A. **Auxiliary (Yardımcı Modüller)**: Exploit içermeyen destekleyici araçlardır. Tarayıcılar (scanners), bilgi toplayıcılar (gather), fuzzers ve DoS araçları buradadır.
B. **Exploits (İstismar Modülleri)**: Hedef sistemlerdeki zafiyetleri tetikleyen kodlar içerir. İşletim sistemlerine ve servislere göre ayrılmıştır.
C. **Payloads (Zararlı Yükler)**: Hedefte çalıştırılacak kodları barındırır. 3 türe ayrılır:
   * **Singles (Inline)**: Kendi kendine yeten, tek parçalı paketlerdir. Ek bir dosya indirmeden doğrudan çalışırlar (örn: `generic/shell_reverse_tcp`).
   * **Stagers**: Hedef ile saldıran makine arasında küçük bir bağlantı kanalı açar. Sonrasında büyük boyutlu asıl zararlıyı (stage) indirir.
   * **Stages**: Stagers tarafından hedef makineye indirilen büyük boyutlu ana zararlı kodlarıdır (örn. Meterpreter).
D. **Post (Sızma Sonrası Modüller)**: Hedef sistem ele geçirildikten sonra yapılacak işlemler (bilgi toplama, şifre kırma, ağda yayılma) için kullanılır.
E. **Encoders (Şifreleyiciler)**: Antivirüs (AV) imzalarından kaçabilmek için payload ve exploit kodlarını şifreler/karıştırır.
F. **Evasion (Kaçınma Modülleri)**: Antivirüs ve savunma sistemlerini doğrudan atlatmak için özel teknikler kullanan modüllerdir.
G. **NOPs (No Operation)**: İşlemciye hiçbir şey yapmamasını söyleyen dolgu komutlarıdır (örn: `0x90`). Payload boyutlarını standartlaştırmak için kullanılır.

> [!TIP]
> **Inline (Single) vs Staged Payload Nasıl Ayırt Edilir?**
> * **Inline (Tek Parça):** İsimler arasında **alt çizgi `_`** bulunur. Örn: `generic/shell_reverse_tcp`
> * **Staged (Aşamalı):** İsimler arasında **taksim `/`** bulunur. Örn: `windows/x64/shell/reverse_tcp`

## 💻 Msfconsole Temel Komutları ve Kullanımı

### 📋 Temel Kullanım Adımları (İş Akışı)
Metasploit ile bir hedefi istismar ederken takip edilen temel adımlar sırasıyla şunlardır:
1. **[Konsolu Başlatma (`msfconsole`)](#step1)**
2. **[Arama Yapma (`search`)](#step2)**
3. **[Modül Seçme (`use`)](#step3)**
4. **[Seçenekleri Görüntüleme (`show options`)](#step4)**
5. **[Parametre Ayarlama (`set`)](#step5)**
6. **[Saldırıyı Başlatma (`exploit` / `run`)](#step6)**

---

<div id="step1"></div>

### 1. 🚀 Konsolu Başlatma (`msfconsole`)
Terminalden Metasploit konsoluna erişmek için:
```bash
msfconsole
```

<div id="step2"></div>

### 2. 🔍 Arama Yapma (`search`)
Veritabanında zafiyet, exploit veya modül aramak için kullanılır:
```bash
# Genel arama
search ms17-010
search apache

# Filtreli arama (Sadece scanner modüllerini getirir)
search type:auxiliary telnet
```

### 🛠️ Modül Seçme ve Bilgi Alma
<div id="step3"></div>

3. **Modül Seçme (`use`):**
  ```bash
  use exploit/windows/smb/ms17_010_eternalblue
  # veya arama sonucundaki index numarası ile:
  use 2
  ```
* **Modül Bilgisi (`info` - Opsiyonel / Ek Adım):** Modülün yazarı, CVE numaraları ve açıklamalarını gösterir.
  ```bash
  info
  ```

4. **Seçenekleri Görüntüleme (`show options`):** Modülün çalışması için gerekli (Required: yes) parametreleri listeler.

  #### 🔍 `show options` Çıktısının Detaylı Açıklaması

  ##### A. Module Options (Exploit'in Kendisine Ait Ayarlar)
  Burada hedefe saldırmak için gereken parametreler yer alır:
  * **⚠️ RHOSTS (Remote Host)**: `Required: yes` ve `Current Setting` boş! ❗
    * **Anlamı**: Saldırmak istediğin hedef makinenin IP adresini girmek zorundasın!
    * **Ne yapmalısın?**: `set RHOSTS <hedef_IP>` yazmalısın!
  * **RPORT (Remote Port)**: `445` olarak ayarlanmış.
    * **Anlamı**: SMB servisinin çalıştığı varsayılan porttur. Değiştirmene gerek yok.
  * **SMBDomain, SMBPass, SMBUser**: `Required: no`
    * **Anlamı**: EternalBlue modülünde kullanıcı adı ve şifre opsiyoneldir (Optional), yani boş bıraksan bile şifresiz saldırır.
  * **VERIFY_ARCH & VERIFY_TARGET**: `true`
    * **Anlamı**: Metasploit saldırmadan önce hedefin işletim sistemini ve mimarisini (x64) kontrol eder, uyumsuzsa saldırmayıp sistemi çökertmekten kaçınır.

  ##### B. Payload Options (Ters Bağlantı / Zararlı Yük Ayarları)
  Exploit başarılı olduğunda hedef makinenin sana nasıl geri bağlanacağını belirleyen ayarlardır (Varsayılan olarak `windows/x64/meterpreter/reverse_tcp` seçilmiş):
  * **LHOST (Local Host)**: `172.20.10.11`
    * **Anlamı**: Hedef makinenin bağlantı kuracağı senin (saldırganın) IP adresi. Metasploit ağ kartından bunu otomatik çekmiş.
  * **LPORT (Local Port)**: `4444`
    * **Anlamı**: Senin bilgisayarında dinlemeye alınacak porttur.
  * **EXITFUNC**: `thread`
    * **Anlamı**: Bağlantı koptuğunda hedefteki sürecin (process) çökmeden arka planda güvenle kapanmasını sağlar.

  ##### C. Exploit target (Hedef Seçimi)
  * **0 Automatic Target**: Metasploit hedefin Windows 7 mi yoksa Server 2008 R2 mu olduğunu kendisi otomatik algılayacaktır.

* **Uyumlu Payload'ları Listeleme (`show payloads` - Opsiyonel / Ek Adım):** Seçilen exploit modülü ile uyumlu çalışan tüm zararlı yükleri (payload) listelemek için kullanılır.
  ```bash
  show payloads
  ```

  > [!IMPORTANT]
  > **Bu Adım Zorunlu Değildir!**
  > Eğer varsayılan olarak gelen payload sizin için uygunsa, `show payloads` komutunu çalıştırmanıza veya yeni bir payload set etmenize gerek yoktur. Sadece hedef IP'yi (`set RHOSTS <hedef_IP>`) ayarlayıp doğrudan `exploit` yazarak saldırıyı başlatabilir ve devam edebilirsiniz.

  #### 🔍 Uyumlu Payload Seçim Kriterleri

  Seçilen modüle göre listelenen onlarca payload arasından en uygununu seçmek için 3 temel kriter bulunur:

  ##### A. Ne Tür Bir Erişim İstiyorsun? (Meterpreter vs Command Shell)
  * **Meterpreter (Gelişmiş Oturum)**: Hedefte dosya indirme/yükleme, şifre karmalarını çekme (hashdump), yetki yükseltme (privilege escalation) gibi gelişmiş Metasploit komutlarını çalıştırmak istiyorsanız adı `meterpreter` olanları seçmelisiniz (Örn: `windows/x64/meterpreter/reverse_tcp`).
  * **Command Shell (Normal CMD/Terminal)**: Sadece düz bir Windows komut satırı (CMD) veya Linux terminali istiyorsanız adı `shell` olanları seçmelisiniz (Örn: `windows/x64/shell_reverse_tcp`).

  ##### B. Bağlantı Yönü Ne Olmalı? (Reverse vs Bind)
  * **Reverse TCP (Ters Bağlantı - Varsayılan & En İyisi)**: İçinde `reverse_tcp` geçenlerdir. Hedef makine dışarıya doğru sizin IP'nize bağlanır. Hedefteki güvenlik duvarlarını (Firewall) aşmak için her zaman ilk tercih olmalıdır.
  * **Bind TCP (Hedefte Port Açan)**: İçinde `bind_tcp` geçenlerdir. Hedef makinede bir port açar ve sizin oraya bağlanmanızı bekler. Sadece hedefin güvenlik duvarı dışarıya bağlantı (outbound) vermiyorsa veya kısıtlıysa kullanılır.

  ##### C. Hangi Protokolü Kullanacaksın? (TCP vs HTTP/HTTPS)
  * **TCP**: En hızlı ve varsayılan bağlantı türüdür (`reverse_tcp`).
  * **HTTP / HTTPS**: Eğer hedef ağda sıkı bir firewall/IPS varsa ve sadece web trafiğine izin veriliyorsa, bağlantıyı normal web gezintisi gibi göstermek için `reverse_http` veya `reverse_https` seçilir.

  > [!TIP]
  > **💡 eJPT İpucu: En İdeal Payload**
  > Arama yaparken veya doğrudan seçim yaparken en sık kullanılan payload:
  > * **64-bit Sistemler İçin:** `windows/x64/meterpreter/reverse_tcp`
  > * **32-bit Sistemler İçin:** `windows/meterpreter/reverse_tcp`
  > 
  > Eğer sadece `set RHOSTS <hedef_IP>` ayarını yapıp başka hiçbir payload belirtmeden doğrudan `exploit` yazıp çalıştırırsanız, Metasploit uyumlu olan varsayılan payload'ı arka planda otomatik olarak seçip çalıştıracaktır.
* **Geri Dönme (`back` - Opsiyonel / Ek Adım):** Seçili modül context'inden çıkıp ana menüye döner.
  ```bash
  back
  ```

## ⚙️ Parametre Ayarlama (Variable Management)

<div id="step5"></div>

5. **Parametre Ayarlama (`set`):** Metasploit modüllerinin çalışması için gereken parametreler `set` komutu ile tanımlanır:
   * **`set RHOSTS <IP>`**: Hedef makinenin IP adresini veya IP aralığını belirler. (Remote Host)
   * **`set RPORT <Port>`**: Hedef servisin portunu belirler. (Remote Port)
   * **`set LHOST <IP>`**: Saldırgan makinenin IP adresini (kendi IP'niz) belirler. (Local Host)
   * **`set LPORT <Port>`**: Ters bağlantının döneceği portu belirler. (Local Port)
   * **`set PAYLOAD <yol>` - Opsiyonel / Ek Adım**: Kullanılacak zararlı yükü seçer.

### 🌐 Global Parametre Ayarlama (`setg` & `unsetg`)
Eğer tarama yaparken sürekli aynı hedef IP'yi kullanıyorsanız, modül değiştirdiğinizde parametrenin sıfırlanmaması için global tanımlama yapabilirsiniz:
```bash
# Global hedef belirleme
setg RHOSTS 10.10.19.23

# Global hedefi temizleme
unsetg RHOSTS
```

### 🧹 Parametreleri Temizleme (`unset`)
* Tek bir parametreyi temizlemek için: `unset PAYLOAD`
* Set edilen tüm parametreleri sıfırlamak için: `unset all`

#### 💤 Arka Planda Çalıştırma (`-z` - Opsiyonel / Ek Adım)


### 📞 Oturum (Session) Kontrolü
Exploit başarılı olduğunda hedef sistem ile aranızda bir **oturum (session)** açılır.

* **Aktif Oturumları Listeleme:**
  ```bash
  sessions
  ```
* **Oturumu Arka Plana Alma (Background):**
  Meterpreter ekranındayken ana konsola dönmek için:
  ```bash
  background
  # veya klavyeden: CTRL + Z
  ```
* **Oturuma Yeniden Bağlanma (Interaction):**
  Arka plandaki bir oturuma (örn: ID'si 2 olan) tekrar bağlanmak için:
  ```bash
  sessions -i 2
  ```
